# نتائج التحقق من النسخة المسلّمة

تاريخ التحقق: 9 نوفمبر 2026. لم يُربط المشروع بحساب Google ولم تُنشأ شيتات أو عمليات نشر فعلية. لم يُقرأ أو يُعدّل NAGY STUDIO.

## ما نُفذ ونجح محليًا

- `npm test`: **53 اختبارًا ناجحًا**، دون اختبارات فاشلة. تستخدم Node.js وخدمات Google بديلة في الذاكرة. اختبارات التكامل تُشغّل ملفات `.gs` وطبقة Storage الفعلية دون إعادة كتابة منطقها.
- `npm run check`: فحص تركيب 10 وحدات JavaScript/Apps Script مضمّنة، وصحة JSON وتوقيت البيان.
- `npm run test:browser`: Chromium عبر Playwright، وخادم معاينة مستقل ينفّذ ملفات `.gs` الفعلية. لا يتصل بـ Google.

اختبارات الخادم تغطي الحساب بالقرش من أسعار الشيت، وتحقق الحقول والهاتف والكميات، ورفض المتغيرات غير المتاحة، ورفض البيع غير الجاهز، ونجاح طلب حقيقي **داخل المحاكاة فقط** بعد اكتمال بيانات مراجعة افتراضية. الدفع عند الاستلام يظل غير مدفوع.

تغطي أيضًا إعادة محاولة الطلب دون تكرار، والتعارض عند تغيير الحمولة، وفشل كتابة البنود جزئيًا والاستعادة، وفقد خطوة إنهاء الحفظ، والسعة والإلغاء المتكرر، وعزل الديمو، وحدود الوقت والهاتف، وإعادة تشغيل setupStore دون فقد الطلبات أو تكرار البيانات، ورفض علامة شيت أجنبي. اختُبرت جميع عمليات الإدارة ضد الهوية المجهولة والبريد غير المصرح واختلاف هوية التنفيذ، وخصوصية الكتالوج، وحفظ نصوص تشبه الصيغ كنص، والتحصيل الجزئي والاسترداد وسجل إعادة محاولة الدفع بعد انقطاع كتابة بعض الخلايا.

اختبار المتصفح يغطي اختيار البرجندي / M وقطعتين، بإجمالي تجريبي 1360 جنيهًا شامل الشحن. يُفقد رد الطلب عمدًا **بعد حفظه**، ثم تُعاد نفس الحمولة والمفتاح؛ يُثبت الاختبار وجود طلب واحد فقط للإدارة. يتحقق من UTM، وأحداث view_item وbegin_checkout وorder_submitted دون بيانات العميل، وعدم إصدار purchase، وعرض الموبايل بعرض 390 بكسل، والكتالوج الناقص الذي يمنع الإرسال. فُحص عرض سطح المكتب أيضًا. الصور المرفقة للمعاينة المحلية وليست نشر Google.

اختُبرت واجهة الإدارة كذلك بمتصفح مع بديل RPC: فتح التفاصيل، وتغيير الحالة، وإدخال مبلغ دقيق، وحفظ الإعدادات، وفقد رد حركة مالية مع إعادة نفس المعرف ورفض تغييره دون مراجعة. اختبارات التكامل المنفصلة تتحقق من تطبيق هذه العمليات على الخادم الفعلي داخل المحاكاة.

## ما لم يُختبر داخل Google

لم تُنفذ مصادقة OAuth أو استرجاع Session الفعلي أو مشاركة الشيت أو اختلاف نوعي النشر. لم يُختبر تزامن طلبات Google الفعلية أو LockService/CacheService أو سلوك Sheets الحقيقي مع الصيغ والمهل والحصص. محاكاة الخادم لا تثبت هذه الخصائص؛ توجد خطوات تحقق مستقلة في [GOOGLE_TESTS.md](GOOGLE_TESTS.md).

التقاط UTM من رابط HTML Service يستخدم google.script.url.getLocation؛ اختبار المتصفح المحلي يتحقق من مسار URL المحلي، ويجب تأكيد المسار داخل iframe المنشور. لا يوجد Meta Pixel مثبت أو اتصال بمنصة إعلانات، ولا يوجد ادعاء بصحة تتبع خارجي.

## ملف Excel المضاف

تم توليد `templates/brand-store-template.xlsx` من بذور الكود ومخططاته، ثم إعادة فتحه للتحقق من التبويبات العشرة وعناوين الجداول وأنواع الأسعار والأعلام والبيانات التجريبية. جداول Orders وOrderItems وAuditLog بلا سجلات. تحققت أمثلة الحساب المحفوظة: 650 + 60 = 710 جنيهات، وعدم وجود ماكرو أو روابط مصنفات خارجية. تمت مراجعة مستقلة للملف الثنائي، وتصديره تجريبيًا إلى PDF عبر LibreOffice وفحص صفحة الدليل بصريًا دون أخطاء صيغ. لم يُختبر نقل القيم داخل Google.

## حزمة النسخ اليدوي والشيت المرتبط

عدّلنا الإعداد الحالي لتهيئة الشيت الجديد الفارغ الذي تُفتح منه Extensions → Apps Script، وحفظ معرفه بدل إنشاء شيت آخر. جرى اختبار رفض الشيت الأجنبي أو تعارض المعرف أو الأعمدة المفقودة/المكررة/المبدلة/الإضافية قبل أي تعديل. اختبرت إعادة التشغيل مع إعدادات معدّلة وطلب محفوظ، واستكمال بذور أول تهيئة بعد انقطاعها، وعدم إعادة SKU تجريبي حذفته الإدارة، والحفاظ على التنسيقات والبيانات. محاكاة الخدمات تُطبق حدود شبكة 26 عمودًا فعليًا، واختُبر توسيع Orders إلى أعمدته الـ28 قبل الكتابة.

المجموع الحالي 53 اختبارًا محليًا ناجحًا. تشمل الاختبارات تعريف قواعد التحقق من البيانات وتنسيق الأموال والهاتف والتاريخ، ولا تثبت تنفيذ محرك التحقق داخل Google. الحزمة المدمجة تشغّل طلبًا تجريبيًا كاملًا وإدارةً من المعرف المحفوظ دون شيت نشط، وتتحقق من الملفات وRPC وعدم تكرار تعريف الدوال. `npm run check` يتحقق أيضًا من تطابق apps-script-ready مع المصدر.

نجح `npm run test:browser:ready` على ملفات الحزمة المدمجة في Chromium: اختيار اللون والمقاس، إجمالي الطلب، فقد الاستجابة بعد الحفظ، إعادة نفس المحاولة مع طلب واحد، ظهوره للإدارة، وUTM وأحداث القياس دون بيانات شخصية. لم تُشغّل setupStore أو قواعد Google أو OAuth أو النشرين على حساب Google.
